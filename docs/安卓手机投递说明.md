# 安卓手机投递到财务工作台

## 平时怎么投

在微信、录音、相册或文件管理器中点“分享”，选择 Syncthing-Fork，并保存到：

`财务工作台投递箱 / 待处理`

Mac 关机时，材料只留在手机本地等待，不会丢失，也不需要云主机、域名或公网服务。

Mac 下次开机后会自动完成：

`手机点对点同步 → 工作台收件 → 录音/视频本机转写 → WorkBuddy 理解并归入事项`

成功收件的原文件会移动到同一投递箱的“已接收”目录；暂未同步完成或暂时读取失败的文件会留在“待处理”，下一轮自动重试。

## 首次安装

1. 安卓手机安装 Syncthing-Fork：<https://github.com/researchxxl/syncthing-android/releases/latest>
2. 在手机端添加 Mac 设备并共享“财务工作台投递箱”。
3. 首次配对完成后，以后只需使用系统“分享”菜单投递。
